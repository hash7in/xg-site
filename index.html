02工艺流程与安全

工艺流程与安全

密闭、无氧、微负压——安全靠结构，不靠人盯。

  1. 01氮气置换制氮机把反应釜内氧气置换出去
  2. 02升温燃油或不凝气加热，2–5 h 升至约 400 °C
  3. 03无氧进料自动上料器连续进料，密封进料段
  4. 04热解分离喷淋气包 → 沉降罐去重油 → 冷凝成燃料油
  5. 05不凝气回用两道水封 + 阻火器进热风炉，为后续批次供热
  6. 06烟气净化二级喷淋脱硫除尘 → 引风机 → 烟囱
  7. 07密封出渣全自动出渣，过程无泄漏

关键控制点

空气进入油气系统密封 + 微负压 + 气密检查 + 氮气接口
不凝气回火水封 + 阻火器 + 止回阀 + 顺序联锁
系统超压压力监测 + 声光报警 + 安全泄放 + 紧急停火
冷却水中断流量与泵状态报警 + 安全停机逻辑
残渣自燃充分冷却 + 开门温度限制 + 密闭输送
停电 / 风机故障燃料切断 + 安全阀位 + 应急电源

排放承诺按项目地标准执行：配脱硫除尘（可选脱硝）可达标，不做「天生达标」的承诺。

约 38% 炭渣 / 回收炭黑 掺煤或生物质燃烧；炼钢增碳剂；深加工为再生炭黑 rCB
